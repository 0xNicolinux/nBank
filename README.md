# nBank

Sistema bancario simples em Java.

## Estrutura

```text
nBank/
├── src/
│   └── main/
│       └── java/
│           └── com/
│               └── nbank/
│                   └── App.java
└── README.md
```

## Executar

```bash
mkdir -p out
javac -d out src/main/java/com/nbank/App.java
java -cp out com.nbank.App
```

Saida esperada:

```text
Bem-vindo ao nBank!
```
